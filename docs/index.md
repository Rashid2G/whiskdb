This is the official project documentation for **WhiskDB**, a database engine designed to run application code directly within the database engine itself.

---

## Project Overview

Traditional architectures separate the database and the application layer with network boundaries. Each query incurs round-trip serialization and network overhead. **WhiskDB** eliminates this boundary by co-locating business logic and state in the same physical memory space.

Inspired by modern data systems such as **[SpacetimeDB](https://spacetimedb.com)** and **[Convex](https://convex.dev)**, WhiskDB combines the speed of in-memory execution with durable persistence and real-time client reactivity.
